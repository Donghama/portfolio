핵심 결정The key decision

AI는 맥락만 주고, 판단은 사용자가 합니다.AI gives the context. The user makes the call.

매칭률과 유형 점수로 AI가 관계를 평가하던 구조를 걷어내고, 사용자에게 맥락만 제공하도록 서비스를 재정의했습니다.I removed the structure where AI graded relationships with match rates and type scores, and redefined the service to give users context only.

리디자인Redesign

무엇을 걷어냈나What I took out

매칭률로 관계를 수치화Relationships reduced to a match rate
→ 관계의 맥락을 보여 줌Show the context of the relationship

→ 판단은 사용자에게 맡김Leave the judgment to the user
